# HTML-Game

Этот проект представляет собой браузерный шутер от первого лица на Three.js с управлением через Pointer Lock API.

## Структура

- `index.html` — точка входа и подключение игрового скрипта.
- `styles.css` — оформление оверлея, HUD и перекрестия.
- `src/game.js` — игровая логика, управление и взаимодействие со сценой Three.js.

## Как протестировать

1. Запустите локальный HTTP-сервер в корне репозитория. Например:
   - Python 3: `python -m http.server 8000`
   - Node.js: `npx http-server . -p 8000`
2. Откройте в браузере страницу `http://localhost:8000/index.html`.
3. Нажмите кнопку **Play** в оверлее, чтобы активировать Pointer Lock, и разрешите браузеру доступ к указателю.
4. Используйте клавиши `W`, `A`, `S`, `D` для перемещения, мышь — для обзора и наведения, `ЛКМ` — для стрельбы.
5. Следите за HUD: индикатор здоровья, счётчик попаданий по корпусу и голове, а также статус перезарядки подтверждают корректную работу логики попаданий.

Для повторного тестирования перезапустите сервер или обновите страницу, чтобы сбросить состояние игры.
