# Neon Arena Multiplayer

Неоновый браузерный шутер с имитацией 3D и поддержкой нескольких игроков. Клиент использует Three.js и Pointer Lock Controls, а синхронизация игроков реализована через Socket.IO.

## Возможности

- Свободное перемещение мышью и клавишами `WASD`, прыжок на `Space`, спринт при зажатом `Shift`.
- Стрельба из пистолета (12 патронов в магазине, 60 в запасе), перезарядка на `R`.
- Серверная проверка попаданий: 4 попадания по корпусу (по 25 HP) или один хедшот для устранения противника.
- Автоматическое возрождение и учёт очков за устранения.
- Журнал событий, счётчик здоровья с полоской и числовым значением, отображение боезапаса с индикатором перезарядки, а также динамический перекрестие и хит-маркер в центре экрана.

## Установка и запуск

1. Убедитесь, что установлен Node.js версии 18 или новее.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите игру:
   ```bash
   npm start
   ```
4. Откройте в браузере адрес [http://localhost:3000](http://localhost:3000) и нажмите на экран, чтобы войти в режим Pointer Lock и присоединиться к матчу.

Для проверки мультиплеера откройте несколько вкладок или браузеров и подключитесь к одному и тому же серверу.

## Структура проекта

- `server.js` — Node.js сервер Express + Socket.IO, отвечает за статику и игровую синхронизацию.
- `public/index.html` — точка входа клиентского приложения.
- `public/styles.css` — оформление HUD и экранных элементов.
- `public/js/game.js` — логика клиента: управление, отображение сцены Three.js и взаимодействие с сервером.
- `package.json` — зависимости и скрипты запуска (`npm start`).

## Тестирование

Автоматические тесты не предусмотрены. Для быстрой проверки функциональности:

1. Запустите сервер командой `npm start`.
2. Подключитесь из двух вкладок браузера.
3. Убедитесь, что перемещение и поворот камеры синхронизируются между игроками.
4. Проверьте механику стрельбы: попадание по корпусу уменьшает здоровье на 25, хедшот мгновенно устраняет противника.
5. После устранения игрок должен возрождаться в одной из точек и получать обновлённый счёт.
