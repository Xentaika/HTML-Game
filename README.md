# Neon Arena Multiplayer

Неоновый браузерный шутер с имитацией 3D и поддержкой нескольких игроков. Клиент использует Three.js и Pointer Lock Controls, а синхронизация игроков реализована через Socket.IO.

## Возможности

- Свободное перемещение мышью и клавишами `WASD`, прыжок на `Space`, медленная ходьба при зажатом `Shift`.
- Серверная симуляция движения с тикрейтом 128 Гц: мгновенный разгон, сбалансированная беговая скорость и гарантированное приземление даже если клиент завис или свернут.
- Стрельба из пистолета (12 патронов в магазине, 60 в запасе), перезарядка на `R`.
- Серверная проверка попаданий: 4 попадания по корпусу (по 25 HP) или один хедшот для устранения противника.
- Автоматическое возрождение и учёт очков за устранения.
- Журнал событий, счётчик здоровья с полоской и числовым значением, отображение боезапаса с индикатором перезарядки, а также динамический перекрестие и хит-маркер в центре экрана.

## Установка и запуск

1. Убедитесь, что установлен Node.js версии 18 или новее.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите игру:
   ```bash
   npm start
   ```
4. Откройте в браузере адрес [http://localhost:3000](http://localhost:3000) (если порт 3000 свободен) и нажмите на экран, чтобы войти в режим Pointer Lock и присоединиться к матчу.

Для проверки мультиплеера откройте несколько вкладок или браузеров и подключитесь к одному и тому же серверу.

## Структура проекта

Проект переработан в сторону модульной архитектуры, чтобы подготовиться к развитию в сторону игры уровня Valorant:

- `server/`
  - `config/movementConfig.js` — параметры физики и тикрейта.
  - `entities/` — базовые сущности сервера (`character`, `player`, `weapon`, `movementInput`).
  - `game/gameWorld.js` — логика арены, столкновений и расчёт попаданий.
  - `network/shooterServer.js` — настройка Express, Socket.IO и игровой петли.
  - `index.js` — точка входа сервера (`npm start`).
- `public/`
  - `index.html` — точка входа клиента.
  - `styles.css` — оформление HUD и экранных элементов.
  - `js/`
    - `core/` — HUD, сетевой клиент, ввод и главный контроллер игры.
    - `entities/` — локальный игрок, удалённые аватары и оружие.
    - `scenes/` — генератор арены.
    - `main.js` — инициализация клиента.

## Тестирование

Автоматические тесты не предусмотрены. Для быстрой проверки функциональности:

1. Запустите сервер командой `npm start`.
2. Подключитесь из двух вкладок браузера.
3. Убедитесь, что перемещение и поворот камеры синхронизируются между игроками.
4. Проверьте механику стрельбы: попадание по корпусу уменьшает здоровье на 25, хедшот мгновенно устраняет противника.
5. После устранения игрок должен возрождаться в одной из точек и получать обновлённый счёт.
